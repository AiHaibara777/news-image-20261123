THE WORLD — Monday, 23 November 2026: a one-page newspaper in a single
1024×1024 image. The hero story is the collapse of the COP31 climate
summit in Antalya, with panels on the Dymer rescue in Ukraine, two
tankers hit in the Strait of Hormuz, the Democrats' largest US House
majority since 1992, the deadly factory fire in Banten, Indonesia, and
sport (Alcaraz's first ATP Finals title, Thitikul's third straight LPGA
finale win), plus a ticker on Libya and the Geneva killer-robot talks.
The image was typeset programmatically so every headline stays crisp.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png`, byte-identical to the `entry.png` held in
this repository. Without `MAKEFUN_OUTPUT_DIR` the program writes to
`/output/entry.png`, as the competition grader expects. Python 3.13,
standard library only, no network needed.
